# 记忆与上下文管理 - 源码分析

## 概览

DeerFlow 的记忆系统提供短期记忆（会话内）和长期记忆（跨会话）管理，支持上下文压缩和摘要。

## 上下文隔离

### 子代理隔离机制
```python
# ThreadState 中的隔离
class ThreadState(AgentState):
    thread_id: str
    sandbox_id: str | None
    # 每个线程独立的上下文
    
# Sub-Agent 隔离
class SubagentExecutor:
    def create_isolated_context(self) -> dict:
        """创建隔离的子代理上下文"""
        # 子代理看不到主代理的完整历史
        # 只有分配给它的具体任务
```

### 隔离原则
1. 子代理只看到分配的任务描述
2. 子代理不继承主代理的完整对话历史
3. 子代理完成后返回结构化结果
4. 主代理汇总所有子代理结果

class MemoryMiddleware(AgentMiddleware):
    def after_agent(self, state, runtime):
        messages = state.get("messages", [])
        filtered = filter_messages_for_memory(messages)

## 设计亮点

### 1. 防抖更新
- 避免频繁LLM调用
- 合并短时间内多次更新
- 节省成本和资源

### 2. 智能过滤
- 只保留重要对话
- 自动检测纠正/强化
- 忽略工具调用细节

### 3. 上下文压缩
- Token 阈值触发
- LLM 生成摘要
- 保留关键信息

### 4. 多级隔离
- 用户隔离
- Agent隔离
- 子代理隔离

### 5. Token归因
- 子代理Token统计
- 归因到主代理
- 成本追踪
